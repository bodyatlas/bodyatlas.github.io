docassemble alternative that needs no server

docassemble is a powerful, free, open-source platform for guided interviews, widely used in access-to-justice projects. It runs on a server you host. Clausery runs in the browser with nothing to install or host.

Choose docassemble if

  • You need public-facing web interviews at scale
  • You have developers comfortable with Python and YAML
  • You need logic beyond what a form designer offers

Choose Clausery if

  • You have no server, no developer and no IT budget
  • Your templates live in Word and should stay there
  • You want a questionnaire from a template in minutes, without code

Try it with your own template

Open the app, drop in a Word document with tags like {client_name}, and you have a questionnaire. Or start from one of the free templates.
